# ☕ Java Fundamentals & Acadêmico

Repositório dedicado aos estudos dos fundamentos da linguagem Java, Orientação a Objetos e estruturas de dados. O repositório contem exercícios práticos do curso online da Udemy (Prof. Nelio Alves) e atividades acadêmicas do curso Análise e Desenvolvimento de Sistemas (UNITAU).

## 📂 Estrutura do Repositório

- /curso-nelio-alves: Exercícios, desafios e projetos práticos do curso completo de Java.
- /unitau-ads: Atividades, trabalhos e listas de exercícios da faculdade.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)
- **Conceitos:** Lógica de Programação, POO, Tratamento de Exceções, Estruturas de Dados
- **IDE:** VS Code e IntelliJ IDEA
